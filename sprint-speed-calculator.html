method

All values are derived from a single internal representation in metres per second.

m/s      = input (or converted from km/h, mph, or pace)
km/h     = m/s × 3.6
mph      = m/s / 0.44704
min/km   = 1000 / m/s / 60     (as M:SS)
min/mile = 1609.344 / m/s / 60 (as M:SS)
split(d) = d / m/s             (seconds)

1 mile = 1609.344 m, 1 mph = 0.44704 m/s.
